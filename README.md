## Project 1: Sales Data Analysis

**Status:** Initial analysis completed

### Project Objective

Analyze product revenue using Python to identify total revenue, compare product performance, and visualize the results.

### Tools and Technologies

- Python 3.15.2
- Visual Studio Code
- Jupyter Notebook
- Pandas
- Matplotlib
- Git and GitHub

### Dataset

The initial dataset contains three products and their revenue.

| Product | Revenue |
|---|---:|
| Laptop | $1,200 |
| Mouse | $150 |
| Keyboard | $300 |

### Key Findings

- **Total Revenue:** $1,650
- **Highest-Revenue Product:** Laptop ($1,200)
- **Laptop Revenue Contribution:** Approximately 72.7%
- **Lowest-Revenue Product:** Mouse ($150)

### Data Visualization

Created a bar chart comparing revenue across the three products using Matplotlib.
